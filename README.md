# NaturaLana Skincare Website 

NaturaLana is a responsive skincare brand website developed as a university project for my **Web Technologies I** course.

The project was designed to apply fundamental front-end web development concepts using **HTML, CSS, and JavaScript**.

## Live Demo

[View the Live Website](https://lanaelleathy.github.io/NaturaLana-skincare-brand-website/)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive skincare brand website
- Product catalogue with multiple skincare categories
- Featured products section
- Contact form with JavaScript validation
- Subscription/registration form
- Interactive image slideshow
- Embedded Google Maps location
- Back-to-top functionality
- Navigation across multiple pages

## Pages

- Home
- All Products
- Contact Us
- Subscribe

## Project Background

This project was developed as part of my **Web Technologies I** university course.

The objective was to design and develop a multi-page website while applying concepts learned throughout the course, including HTML page structure, CSS styling and layouts, navigation, forms, and JavaScript functionality.

## What I Learned

Through this project, I gained practical experience with:

- Structuring multi-page websites with HTML
- Styling responsive webpages using CSS
- Adding interactivity using JavaScript
- Creating and validating web forms
- Organizing website files and assets
- Using relative file paths
- Using GitHub for version control and project hosting
- Deploying a website publicly using GitHub Pages
